# 擬似SBI証券・アルゴリズム取引＆特殊注文検証シミュレーター

実在するネット証券（SBI証券 PC版取引画面）の無骨で情報密度の高いUIを極限まで再現した、フロントエンド完結型の高性能デモトレード・シミュレーターです。NISA制度を排し、特定口座・一般口座での本格的な現物株取引の練習に特化しています。

インターネットからパブリックCORSプロキシを介して実際のリアルタイム日本株データをフェッチし、特殊注文（指値・逆指値）や自動売買ロボットの自律アルゴリズムをノーリスクで実験・検証できます。

## 主な機能

### 1. SBI証券PC版を再現した高密度UI
*   伝統のSBIネイビー（#113366）を基調とした、実用本位で無骨なデザイン。
*   金額・数量の桁ずれを防ぐ等幅フォント（monospace）の採用と3桁コンマ区切り表現。
*   国内株仕様のカラーリング（上昇：赤 / 下落：緑）。

### 2. プロ仕様の詳細な執行条件・特殊注文
*   成行・指値はもちろん、レンジ上抜け追随やストップロス（自動損切り）に不可欠な「逆指値注文」を完全再現。
*   1秒周期のバックグラウンド約定（マッチング）エンジンが最新株価と注文条件を常に照合。
*   約定時にはSBI証券を模したトースト通知と電子アラート音が発報。

### 3. リアルタイム株価連動 & 擬似「板情報（気配値）」
*   パブリックプロキシ経由でYahoo Financeから実在する主要4銘柄（トヨタ・ソニーG・三菱UFJ・任天堂）のリアルタイム株価を取得。
*   現在値を中心に上下5本ずつの気配数量がピコピコとリアルタイムに微変動する、臨場感ある「板情報」生成エンジン。
*   堅牢なフォールバック機能: 外部APIエラーやオフライン時には、自動的に内蔵されたなめらかなダミー株価駆動モードへ切り替わり、システムダウンを防止。

### 4. 実験用「自動売買ロボット（アルゴリズム取引）」
*   「AI」という曖昧な表現を排し、JavaScript内で厳密に計算されたテクニカル指標（短期・中期移動平均線）をベースに自律稼働。
*   ゴールデンクロスで自動的に「逆指値買い」、デッドクロスやロスカット閾値（-2.0%）到達で自動的に「成行売却・損切り」を執行。
*   ロボットが自律判断した思考プロセスをリアルタイムに出力する、コンソール風の「ロボット自動発注ログ」を搭載。

## 技術スタック
*   Language: HTML5 / CSS3 / JavaScript (ES6+)
*   Framework: なし（外部ライブラリ・APIキー一切不要の Vanilla JS 完結）
*   Architecture: 単一ファイル（All-in-One）によるクリーンな状態管理（SPA）

## 免責事項
本アプリケーションは取引の練習、およびJavaScriptによるアルゴリズム検証を目的とした「シミュレーター（デモ画面）」です。実際の証券口座との連動や、本物の資金を用いた取引機能は一切含まれていません。
